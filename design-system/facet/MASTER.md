# FACET 人格切面｜设计系统主文件

> 项目规格优先于数据库自动推荐。初次检索返回的玻璃拟态、蓝紫色与远程字体均与已批准规格冲突，已明确弃用。本文件是实现阶段唯一视觉事实源。

**艺术方向：** 一个面向中文年轻用户的温暖、清醒的自我观察界面，以“城市线路图上的人格切面”为隐喻，使用独立杂志式宋体标题、系统无衬线正文、暖纸与墨色、高辨识珊瑚信号，以及克制的线路绘制动效。

## 1. 五项冻结决策

1. **字体：** 标题使用本地宋体栈；正文使用系统无衬线。禁止远程字体。
2. **颜色：** 暖纸为唯一页面底色，墨黑为主字色，珊瑚为主行动色，酸绿只作小面积信号。
3. **空间：** 4px 基准；阅读栏最大 720px；宽版结果可扩展到 1120px。
4. **形状：** 4px / 12px / 999px 三种圆角；薄墨线优先，不把每段内容装进卡片。
5. **标志性母题：** 32 个站点组成持续生长的线路；站点形状、编号和文字共同表达状态，不依赖颜色。

## 2. 语义色

| 角色 | 值 | 变量 |
|---|---:|---|
| 页面暖纸 | #F4F0E8 | --color-paper |
| 主墨色 | #171716 | --color-ink |
| 次级文字 | #5E625F | --color-muted |
| 珊瑚信号 | #F4553D | --color-signal |
| 酸绿提示 | #C9F66F | --color-acid |
| 深色封面 | #20221F | --color-night |
| 浅色分隔 | #D5CFC4 | --color-rule |
| 反色正文 | #F8F5EF | --color-on-night |

- 主按钮：珊瑚底＋墨黑字；悬停加深，不用发光。
- 结果封面：深色底＋暖白字；酸绿只用于天气/状态短标签。
- 错误与危险动作必须有明确文字，不能只用红色。
- 正文与背景对比至少 4.5:1；大字和图形至少 3:1。

## 3. 字体与字号

- 标题栈：STSong, Songti SC, SimSun, serif。
- 正文栈：-apple-system, BlinkMacSystemFont, Segoe UI, PingFang SC, Microsoft YaHei, sans-serif。
- 展示：clamp(2.6rem, 8vw, 5.8rem)，行高 0.96–1.05。
- H1：clamp(2rem, 5vw, 4rem)；H2：clamp(1.5rem, 3vw, 2.5rem)。
- 正文：1rem，行高 1.72；小注释不低于 0.75rem，关键说明不低于 0.875rem。
- 中文正文每行约 24–36 字；避免孤立单字换行。
- 所有分数使用等宽数字特性 font-variant-numeric: tabular-nums。

## 4. 空间、宽度与层级

- 空间：4 / 8 / 12 / 16 / 24 / 32 / 48 / 72px。
- 移动端左右边距 16px；平板 32px；桌面 48px。
- 阅读容器 max-width: 720px；结果布局 max-width: 1120px。
- z-index 只使用 0 / 10 / 20 / 40 / 100。
- 页面采用章节式节奏：密集答题与宽松结果段落交替。
- 禁止横向滚动；固定元素必须为正文预留空间。

## 5. 组件准则

### 按钮

- 最小 44×44px；按钮间距至少 8px。
- 主按钮为实心珊瑚；次按钮为透明底＋1px 墨线；文字链接只作三级动作。
- hover/active/focus 不改变外部尺寸；focus-visible 使用 3px 珊瑚轮廓和 3px offset。
- 禁用状态必须使用 disabled 属性、文字说明和降低强调。

### 答案选项

- 使用原生 radio 和显式 label；整行可点击，最小高度 56px。
- 选中态同时出现实心站点、边框变化和“已选”屏幕阅读器文本。
- 数字 1–5 是键盘快捷方式；不把数字作为唯一选项含义。

### 数据呈现

- 六维得分使用 meter、可见数字和两端文字；线路图只是装饰层。
- 类型清晰度使用“双切面／偏向／较清晰／自由切面”文字，禁止伪准确率。
- 天气交界必须明确写出“天气正在交界”。

### 卡片与表面

- 首页事实块可使用薄线分栏，不使用三张同款圆角卡。
- 强阴影只允许分享卡预览或真正浮层；普通内容以分隔线和留白分层。
- 确认删除采用原生 dialog 或清晰的内联确认区，不使用装饰性 blur。

## 6. 页面构图

- **欢迎页：** 巨型两行主标题＋一条穿过首屏的 32 站线路；主按钮紧随价值说明。
- **说明页：** 两种时间框架并列说明，移动端上下排列；答案刻度先演示再开始。
- **答题页：** 当前站点编号作为杂志页码，题目是视觉主角；线路进度保持可见但不抢夺注意力。
- **状态分章：** 在第 25 题前用短暂深色章节幕区分“通常的你”与“最近两周”。
- **结果页：** 深色封面 → 运行说明 → 六维线路 → 证据 → 相邻切面 → 天气 → 行动建议。
- **图鉴／历史：** 使用目录与档案索引语言；条目可以有分隔线，不做无逻辑 bento。

## 7. 动效预算

- 点击反馈 120–180ms；选项与页面过渡 180–320ms；结果线路仅首次绘制，最长 700ms。
- 只动画 transform 与 opacity；输入反馈须在 100ms 内出现。
- 不使用 GSAP、滚动劫持、粒子、视差或连续装饰动画。
- prefers-reduced-motion: reduce 时禁用变换、关键帧、平滑滚动和延时展示；内容必须立即完整出现。

## 8. 响应式与无障碍

- 必测宽度：360、390、768、1024、1280、1440px；同时检查移动端横屏与 200% 缩放。
- 使用 main/header/nav/section/fieldset/legend 等语义结构。
- 提供跳到主内容链接；路由式换屏后把焦点移到主标题。
- 标题层级连续；所有图标/图形有合适 aria-hidden 或可访问名称。
- 颜色从不作为唯一信息；线路站点同时用编号、形状和文本状态区分。
- 所有破坏性动作二次确认；提示区域使用 aria-live=polite 且不抢焦点。

## 9. 明确禁止

- 玻璃拟态、蓝紫渐变、通用 SaaS hero、排行榜、远程字体/图片/脚本。
- emoji 作为结构图标；随机图标家族；每段文字一个圆角卡。
- 把“高级感”做成大量模糊、阴影、3D 或持续运动。
- 精确率、稀有度、诊断性措辞，或把状态结果写成固定人格。

- [ ] 焦点清晰，路由换屏后的焦点位置正确。

- [ ] 结果图表有 meter、数值、端点文字和文本摘要。
- [ ] 本地历史可清除，破坏动作有确认。
